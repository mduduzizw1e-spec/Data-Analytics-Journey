# Portfolio Projects

Use this folder for polished end-to-end projects that you would show to employers.

## Portfolio Project Standard

Each project should include:

- A clear business question
- Data source notes
- Cleaning steps
- Analysis notebook, SQL file, Excel workbook, or Power BI report
- Visual evidence
- Key insights
- Recommendation
- A strong README

Start by copying `../00 Templates/project-template` into this folder and renaming it.
