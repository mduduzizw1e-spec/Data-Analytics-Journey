# Templates

Reusable templates for analytics projects, notebooks, and documentation.

## How To Use

Copy `project-template` into the correct project area, rename it, and complete the included documents as you work.

Example:

```powershell
Copy-Item "00 Templates\project-template" "05 Portfolio Projects\customer-churn-analysis" -Recurse
```

Then update the new project's README, brief, data dictionary, notebooks, and findings summary.
