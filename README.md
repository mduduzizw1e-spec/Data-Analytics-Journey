# Data Analytics Journey

This workspace tracks my path from beginner to job-ready data analyst.

## Learning Tracks

1. `01 Excel Projects` - spreadsheet analysis, pivot tables, formulas, dashboards, and business reporting.
2. `02 SQL Projects` - querying, joins, aggregations, window functions, and database analysis.
3. `03 Python Projects` - pandas, visualization, statistics, notebooks, and repeatable analysis workflows.
4. `04 PowerBI Dashboards` - data modeling, DAX, dashboard design, and stakeholder reporting.
5. `05 Portfolio Projects` - polished end-to-end projects suitable for GitHub, LinkedIn, and interviews.
6. `06 Datasets` - shared datasets used across learning and projects.
7. `07 Career Portfolio` - resume, case studies, interview prep, and profile materials.
8. `08 Notes and Cheat Sheets` - personal references for tools, formulas, patterns, and lessons learned.
9. `09 Practice` - daily drills, challenges, and mistake logs.

## Recommended Project Workflow

Use `00 Templates/project-template` whenever starting a new project.

1. Define the business question in `docs/project_brief.md`.
2. Store original files in `data/raw` and never edit them directly.
3. Clean or transform data into `data/processed`.
4. Explore the data in `notebooks`.
5. Keep SQL queries in `sql` and reusable Python code in `src`.
6. Save charts, summaries, and exports in `reports`.
7. Write final insights in the project `README.md`.

## Portfolio Standard

A job-ready analytics project should clearly show:

- Business problem
- Data source and limitations
- Cleaning and preparation steps
- Analysis method
- Visual evidence
- Key insights
- Recommendation or next action
- Tools used
- How to reproduce the work
