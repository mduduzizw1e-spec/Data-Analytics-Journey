# Career Portfolio

Use this folder to prepare job-search materials and interview evidence.

## Suggested Contents

- `case-studies` - polished summaries of your best projects.
- `resume` - analyst resume versions and bullet drafts.
- `linkedin` - profile notes, headline ideas, and post drafts.
- `interview-prep` - SQL questions, business case practice, and behavioral stories.

## Case Study Structure

1. Problem
2. Data
3. Method
4. Insights
5. Recommendation
6. Business impact
7. Tools used
