# Datasets

Shared datasets live here.

## Folder Rules

- `raw` - original data exactly as downloaded or received. Do not edit these files.
- `processed` - cleaned, transformed, or analysis-ready datasets.
- `external` - third-party reference data, lookup tables, or benchmark files.
- `sample` - small safe datasets for practice or sharing.

## Good Data Habits

- Keep a note of where each dataset came from.
- Record the date accessed.
- Do not commit private, sensitive, or very large data files.
- Create a data dictionary for serious projects.
